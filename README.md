# Harit & Shreya Wedding Website

## Run locally
Install Node.js 20+, then:

npm install
npm run dev

Open http://localhost:3000

## Customize
Edit `components/WeddingSite.tsx` to replace temporary gallery photos, add exact venues, and replace the RSVP `href="#"` with your Google Form URL.

## Deploy
Push to GitHub and import the repository into Vercel. A custom domain can be connected later in Vercel project settings.
